# Tu app del coche (Ford conectado)

App para ver el estado de tu Ford desde el iPhone: cierre, gasolina, presiones, trayectos con mapa,
consumo real, batería, mantenimiento, precios de gasolina, widget y Siri.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/alvarogp30699/fiesta-st-garaje/tree/main/plantilla)

Guía paso a paso: pídesela a quien te ha pasado este enlace.

- Tu servidor y tus datos son solo tuyos (tu cuenta de Cloudflare, gratis).
- La app del móvil: https://alvarogp30699.github.io/fiesta-st-garaje/ (se configura con la URL de tu servidor y tu contraseña).
- Para conectar con Ford: abre un Codespace de este repositorio y sigue `herramientas/LEEME.md`.
